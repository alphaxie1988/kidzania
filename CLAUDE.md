# Kidzania Ticket Visualiser

## What
Next.js 15 web app for visualising Kidzania event tickets.
- Stack: Next.js 15, React 19, TypeScript, Tailwind CSS
- Structure: `app/` (App Router), `components/`, `lib/`

## Why
Generates and displays ticket layouts for Kidzania events.

## How
```bash
npm run dev      # http://localhost:3000
npm run build
```
No environment variables required — fully static, no external APIs.
